# 桌宠位置

> 当前版本、恢复点和完成状态统一见[当前状态](current-status.md)。本文的历史验收段落只描述当时结果。

2026-10-30 修正直接拖动到角落后被推回：原插件接受的拖动在松手时，若图片落点同时距水平边和垂直边不超过32个CSS像素，则进入相应角落停靠，保持12px边距并为内容预留侧边空间。其他落点仍为自由模式，保留控件避让。只在一次拖动结束时选择，不在移动中反复吸附；按压回弹时重新抓取也使用稳定尺寸。取消、非主指针、原插件未接受的点击不提交停靠。菜单四角选择保留。

v30 仅跟踪原插件实际接受的主指针移动。右键、中键、其他指针和关闭菜单的点击不提交新的位置；正常拖动仍交给原插件。松手事件丢失后，释放状态的指针移动会清理适配层的拖动保护；窗口重新获得焦点时，原插件已经结束的手势也能恢复布局。指针取消保留原角落选择，不强行结束原插件仍在进行的拖动。这不是对原插件全部多指触控行为的改写。

v29 保留 GitHub 原项目0.4.2插件文件，不修改原生点击、动画、吸附和保存逻辑。修复的是额外适配层：使用未经过按压缩放和位置过渡的布局尺寸，避免按压/移动后反复修正坐标。该历史阶段手动拖动达到原插件3px阈值后改为“自由”，让原生吸附设置决定落点；现已按上方规则修正角落落点。即使拖出去再拖回来也按拖动处理，取消手势不提交。需要固定四角时仍用下方菜单按钮选择。

余额气泡与角色位置分开计算。单击/双击沿用原插件的泡泡队列，余额气泡优先找视口内空位，空位不足时保留原生可见浮层；不会再因压到附近控件直接透明。原有自动收起时长和气泡开关保留；页面无空位时气泡可能暂时覆盖内容，可按原插件方式收起。展开VM摘要、禁用插件时角色整体隐藏的规则不变。

v28 在 Plugins → dsh-whale-widget 详情中提供独立“桌宠显示与位置”区。桌宠看不见时点“显示桌宠”，会收起VM摘要并尝试自由位置；点“重置位置”选回右下。两种操作均保留实际控件避让，空间不足仍显示暂时隐藏的说明。

关闭插件或组件时，旧图片节点也会隐藏，恢复区说明未运行并禁用按钮。需要手动打开原有插件开关；若开关已开但网页挂件尚未加载，刷新页面。恢复按钮不代替插件启用，也不清除角色、尺寸等设置。窄屏详情中的组件说明使用整行，避免逐字换行。

需要贴角时，打开桌宠菜单，在底部“位置”选择左上、右上、左下或右下。选择“自由”或拖到角落范围以外后恢复整页宽度及原生移动。停靠为图片本体留12px边距，应用界面让出侧边空间，因此输入框和发送按钮不会再把它推到中部。窄窗口会限制显示尺寸，原插件的大小配置保留；回到大窗口或自由模式后恢复相应显示。

四角选择记在当前浏览器的49226来源本地偏好中；刷新可恢复，清除站点数据、换浏览器/端口后需重新选。存储不可用时菜单显示“仅本页”。上角打开菜单时会把菜单放回视口内，必要时可滚动；卸载/关闭桌宠后释放预留宽度。展开VM详情或有其它固定控件实际占住停靠位时仍临时隐藏，保护操作入口。以下v26说明仅适用于“自由”模式。

v27b的插件页dsh-purge悬浮按钮也会随停靠区域移动，停靠时让开底部VM状态栏。已在真实1280×720及425×664插件页检查到桌宠与按钮不重叠；冷启动后聊天页的右下停靠、菜单和输入框可用性通过。只针对当前插件版本与这些实际窗口验收，不保证所有第三方固定浮层都能自动改位。

在日常聊天或插件详情中，按住桌宠图片本体上下拖动。右上角菜单用于角色、大小和提示设置；“大小”滑块不用于调整上下位置。

v26 修复的是 Mac 本机网页入口为隔离 VM 注入的控件避让逻辑。原来仅尝试当前点与六个固定位置，可能在其它空隙可用时隐藏，或把拖动位置大幅改掉。现在清晰位置保持不动，否则在允许区域内选取距请求点最近的空位，保留与控件4px、视口顶部/两侧12px及底部64px留白。插件0.4.2、角色和尺寸设置不变，原插件仍负责保存拖动偏好。

同一偏好在不同页面可能被调整到不同的安全位置；切换页面或控件出现后会重新避让。完全没有空位、展开 VM 状态详情等情况仍可暂时隐藏。窄窗时可收起侧栏或扩大窗口；这项修复不承诺覆盖所有按钮或所有布局下始终显示。

实际425×664窗口中已验证插件页上下拖动、聊天页向下60px、刷新后保持以及返回插件详情保留位置。几何与焦点自动回归覆盖间隙、最小移动、边界、完全遮挡、隐藏/恢复和拖动保护；有限夹具及一次真实页面观察不代表所有时序或持续帧率保证。VM 原始端口49224及其它机器若不使用本仓库相同网页入口，不会自动得到此宿主入口修复。
