# 存储监测与清理预览

在 Mac 打开 `Harness.command`，选择 **12**。同一入口也可运行：

```sh
python3 scripts/storage_preview.py
python3 scripts/storage_preview.py --json
```

这是按需只读检查，不创建定时任务、不自动启动 VM，也没有删除、apply、prune 或自动清理入口。VM 未运行时会显示“未启动”，宿主恢复目录仍可读取；不能将未读取的 VM 用量当作零。

报告包含承载 VM 的 Mac 文件系统空间、主盘逻辑大小/已分配空间、恢复点与归档镜像，以及 VM 文件系统空间、inode、七类目录和 Docker 汇总。检查默认预留线：可用少于 **10GiB 或 15%** 为预警，少于 **5GiB 或 5%** 为紧急；VM 可用 inode 少于15%/5%也会预警/紧急。该策略是可见的提醒阈值，**不代表空间已耗尽，也不会触发删除或强制停止任务**。报告是检查时点的观察，不是持续告警或配额执行器。

VM 内可直接运行：

```sh
python3 /home/purge/tools/dsh-purge-personal-1.1.77-personal.1/scripts/security-storage-preview.py
```

该命令固定读取已知目录元数据：项目文件、审计与报告、程序与扫描资产、下载与验收目录、漏洞库备份、扫描器清单备份、私有会话目录。它不读取文件内容，也不展示账号目录子项。目录从逐层固定的只读描述符打开，不跟随链接；硬链接在同一对象内去重。权限不足、目录变化、读取预算用尽都会标注为未确认/partial，数值仅是已观察的下界。缺失不等于零占用。

每个目录最多30,000项、2秒、32层；下载目录仅扫描前512个入口并最多列20个安全名称子目录，每项最多10,000项、0.15秒。目录检查不是原子快照，活动文件可能变化。目录可能重叠，不应相加；allocatedBytes仅统计普通文件分配块，不包含目录元数据，不等于实际可释放量。

清理预览只给出两种结果：

| 结果 | 含义 |
|---|---|
| 保留 | 日常主盘、当前/基础/近期受保护恢复点、项目、账号、审计和回滚资料 |
| 待人工核对 | 下载子目录、旧恢复点或归档镜像；列出对象、可观察大小和保留/核对依据，**尚未获得删除授权** |

文件年龄、Docker的“可回收”估算或待核对标签都不能作为删除依据。快照与COW镜像共享空间，快照单项及实际可释放量保持未知。Docker镜像、容器和卷均保留，工具不调用清理API。需要删除时，必须另行核对精确路径、身份、运行引用和恢复依赖，并取得针对具体对象的确认。

复用现有恢复目录的有界分页。JSON返回 `nextArchiveCursor` / `nextSnapshotCursor` 时，可分别传入 `--archive-after` / `--snapshot-after` 继续；没有游标但目录不完整时，应查看 `catalogScan` 的错误/深度/入口限制原因，不能推断不存在其他对象。当前页没有候选不等于整机没有可核对项。

本轮没有清理现有项目、审计、账号、备份、镜像或快照。详细实际用量预览保留在本机验收目录，不上传公开仓库。此前[扫描器单次输出限额](scanner-admission.md)继续生效；这里没有新增全 VM 磁盘配额、累计数据保留期限或后台通知。
