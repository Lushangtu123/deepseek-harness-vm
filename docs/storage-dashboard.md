# 容量面板与持续预警

打开本机 [容量面板](http://127.0.0.1:49226/__harness/storage)。聊天页右下角 VM 状态栏会附带“存储：正常 / 容量预警 / 容量紧急 / 待重新核对”等状态；展开状态栏后可点击“存储容量”。旧页面需要刷新一次以加载新增入口。

面板展示承载 VM 的 Mac 文件系统、VM 可用空间与比例，以及 VM 可用 inode。绿色正常、橙色预警、红色紧急；不能确认的数据单独标注。可用少于10GiB或15%预警，少于5GiB或5%紧急；VM inode按15%/5%检查。预留线用于提醒，不会终止任务或清理文件。

现有本机入口进程运行期间每60秒共享采样一次，使用固定 `manage.py storage-capacity` 和 VM 内 `security-storage-preview.py --capacity-only`。轻量模式只读取文件系统计数，不遍历目录、不调用Docker、不读取项目或账号内容。多个页面读取同一份共享结果；页面可见时每15秒刷新显示，隐藏时停止网页轮询。“立即核对”可请求一次采样，并发请求合并，5秒内重复请求复用状态。

持续采样不依赖页面保持打开，但入口退出或Mac睡眠时停止。不会唤醒Mac或启动已停止的VM；VM停止时只显示宿主数据。这里没有新启动项、系统推送、邮件通知或跨设备通知。结果只保存在入口进程内存，退出后清空。

超过90秒、采样失败、时钟反向或跨越长时间暂停的响应不会作为当前正常状态展示。采样和浏览器请求跨越15秒以上的计时缺口时拒绝旧结果；普通浏览器请求有12秒取消期限。上次结果可保留为历史数值，但不能证明当前容量正常。

这里只展示容量。目录、Docker、主盘、快照和归档的保留/待核对信息继续由[启动器选项12](storage-preview.md)按需提供。没有自动清理、删除接口、全VM配额或自动保留策略。实际清理仍需核对精确对象、运行引用和恢复依赖，并取得具体确认。
