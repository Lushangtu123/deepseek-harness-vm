# 桌宠与插件页浏览器验收

涉及网页入口、桌宠、插件详情布局的更新，按以下固定流程验收。代码回归通过后仍须在真实浏览器操作；模拟DOM夹具不执行真实CSS。没有执行的项记为“未验证”，保留失败记录与截图，不以最后一次成功覆盖历史。

| 步骤 | 操作 | 通过信号 |
| --- | --- | --- |
| 1 · 窄屏卡片 | 425×664打开Plugins → dsh-whale-widget | 说明文字整行、可读；开关可见可操作；没有逐字窄列。记录说明宽度，当前目标至少180px。 |
| 2 · 独立恢复 | 插件详情中展开VM摘要使桌宠临时隐藏，再用详情中的“显示桌宠” | 恢复按钮仍在桌宠外；关闭摘要并转自由位置；按实际可用空间显示，或明确说明仍被遮挡。 |
| 3 · 重置位置 | 点击“重置位置” | 右下位置被选中，仍遵守控件避让；状态以真正显示/隐藏为准。 |
| 4 · 四角与菜单 | 正常宽窗口中依次选四角，打开菜单 | 图像在四角留12px边距；菜单位于视口内；输入框和控件仍可用。 |
| 5 · 切换页面 | 插件列表、桌宠详情、既有合成聊天互相切换 | 独立恢复区仅出现在对应详情，不重复挂载；位置保持。 |
| 6 · 刷新 | 选择右下后重新加载浏览器页面 | 同一浏览器来源恢复该位置，桌宠可见或准确说明遮挡。 |
| 7 · 关闭与恢复插件 | 记录原启用状态，临时关闭桌宠插件，再恢复 | 关闭时详情恢复区解释“未运行”、按钮禁用；恢复原启用状态后按钮和桌宠恢复。已开启但脚本尚未加载时按提示刷新；不自动启用插件。 |
| 8 · 冷启动 | 保存新的独立恢复点后正常关闭、启动原VM，再加载页面 | 版本与恢复点覆盖匹配；桌宠及独立恢复区正常。 |
| 9 · 连续拖动 | 大窗口连续拖到三个不同位置，松手后多次观察 | 模式回到自由，原生吸附仍可用；稳定位置不来回修正。保留坐标观察和截图，原生按压弹性不当作抖动。 |
| 10 · 余额气泡 | 自由位置、右下停靠及聊天页分别双击角色，观察淡入和自动关闭 | 余额文字真正可见，气泡不被适配层透明化；打开气泡不推移角色。刷新后重复一次。 |
| 11 · 非拖动操作 | 选右下后右键、中键或点击图片关闭菜单 | 角落预设保持；原插件接受的下一次主指针拖动才转为自由。 |
| 12 · 恢复目录分页 | 从VM摘要打开恢复点管理，逐次点击“加载下一批” | 旧记录保留、不重复；全部批次完成后按钮隐藏；扫描缺口不因下一页成功而消失。 |
| 13 · 磁盘快照分页 | 首批核对重要恢复点，用独立“加载更多快照”继续，中途加载镜像归档 | 已加载快照保持、无重复、两份续页互不重置；全部完成后相应按钮隐藏。真实数据不足80项时使用明确标记的合成大列表另验。 |

记录窗口尺寸、程序/入口版本、位置、可见状态和实际检查过的截图。临时视口覆盖在结束时清除；恢复插件原启用状态，最后保留右下停靠。只使用既有合成聊天，不发送消息或执行聊天内容。关闭插件属于运行配置变动，验收后核对当前VM配置和备份是否一致。

浏览器存储拒绝、恶意或损坏回包、完全无空位和指针取消等异常由对应自动夹具补充；未在真实浏览器触发的异常不写成实际界面通过。隐藏可能来自正常的控件保护；“显示桌宠”不绕过这种保护。此流程覆盖列出的页面与窗口，不代表所有第三方插件布局。

丢失 pointerup、无按钮移动、多指针交错、焦点回归与监听器执行顺序使用受控夹具补充；未在真实设备触发时不可记为真机验收。目录单项超预算或读取失败仍需明确报告，不等同于正常分页。
